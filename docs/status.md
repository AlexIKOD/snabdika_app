# Текущий статус и решения

Срез: **24 октября 2026 года**. Документ описывает фактическое состояние и
договорённости; исторические отметки о завершении работ не являются
доказательством приёмки.

## Подтверждено пользователем

| Решение | Реализация |
| --- | --- |
| Основной исходник базы — `База_нормализации.xlsx` | Отдельный тестовый импорт; рабочий импорт не подключён |
| AI-провайдеры — Gemini и OhMyLama, переключение в настройках | Сопоставление в приложении работает |
| Закупочная и продажная цены хранятся раздельно | Да, с источниками и валидацией |
| Нет цены продажи или неясна единица — счёт блокируется | Backend-валидация и сквозной тест |
| Счёт тестируется в рабочем «МойСклад» | Непроведённые TEST-счета №6761 и №6824; №6824 сверен с предпросмотром до копейки при скидке 10 % и НДС 20 % |
| Один счёт собирается из одного документа | Подтверждено, включая частичный счёт |
| Режим расчёта и НДС задаются в шапке заявки | Реализовано: один объект на заявку, снимок счёта его сохраняет |
| При убытке — только предупреждение | Подтверждено, без автоповышения цены |
| Себестоимость — полная закупка целиком | Подтверждено |
| В одной строке интерфейса — одно акцентное действие | Реализовано в шапках, тулбарах и строках таблиц |

## Известные ограничения

| Приоритет | Ограничение | Где |
| --- | --- | --- |
| Блокер | Импорт нового Excel не понимает колонки `Исходное` и `Нормализованное` | `app/src/features/import/productImport.ts` |
| Высокий | Desktop-импорт Parquet смешивает коды разных поставщиков и стирает цену пустым значением | `app/src/services/parquetCatalog.ts` |
| Высокий | Запись Parquet неатомарна, типы полей переводятся в строки | `app/src-tauri/src/main.rs` |
| Средний | Распознавание изображений и файлов не подключено к интерфейсу | раздел «Заявки» |
| Средний | Статус документа на backend остаётся «Черновик» после подтверждения строк; интерфейс выводит статус из позиций | `app/backend/main.py`, `app/src/lib/requestMeta.ts` |
| Средний | Источник «ИИ» определяется по префиксу номера документа | `app/src/pages/RequestsPage.tsx` |
| Низкий | Названия части материалов содержат лишний префикс категории | данные каталога |
| Низкий | Тёмная тема и мобильная вёрстка не поддерживаются | `app/src/styles/` |

Дефект «10% в mock-счёте» относился к демонстрационному режиму и не описывает
налоговую рекомендацию. Поиск и ранжирование требуют работы с условными
заменами, дублями одной товарной разновидности и доказательностью объяснений
модели.

## Следующие задачи

1. Рабочий импорт нормализованного Excel и перенос алиасов.
2. Распознавание изображений и файлов, встроенный чат.
3. Безопасная запись Parquet и постоянные идентификаторы товаров.
4. Постоянный кеш распознавания, поиска и оценки — [схема](ai-workflow.md#кеширование-и-объём-передачи).
5. Статусы документа на backend и источник ИИ как отдельное поле.
6. Проверка релизного установщика и native-окна.
