## Исторический процесс выпуска (не исполняется; команды и файлы ниже удалены 2026-09-28)

```powershell
python prototype\normalize_all_top500.py
python -m pytest -q prototype\tests
python prototype\audit_strict_qa.py database\moysklad_top\top500_normalized.parquet
python prototype\generate_md_comparison.py
```

Нормализация всегда начинается с головного субъекта и исключает предложные/зависимые группы из доказательств типа. В `raw_only` движок только канонизирует подтвержденные факты. `evidence_enriched` требует точного артикула/SKU и сохраняемой provenance-записи. Недостаток данных приводит к `needs_review`, но не ослабляет критический gate.

Кандидат выпуска хранится в `database/moysklad_top/.normalization_releases/staging/<run-id>/`. При ошибке тестов, QA, сверки форматов или блокировке Excel канонические файлы остаются без изменений; частично заменённые файлы восстанавливаются из `backups/<run-id>/`. Файлы с суффиксом `_final` больше не создаются.
