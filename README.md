# Снабдика · Snabdika_app

> Windows-приложение для подбора строительных материалов по заявкам клиентов и выставления счетов в «МойСклад».

Проект сводит прайсы поставщиков в единый каталог, помогает оператору собрать счёт из заявки клиента, из внутреннего каталога или через ИИ-подбор и отправляет готовый документ в «МойСклад». Интерфейс — React + TypeScript, оболочка — Tauri 2, локальный сервис — FastAPI + SQLite.

**Состояние на 24 октября 2026 года:** подбор возвращает варианты с классом «точное / возможное / аналог» и сразу подставляет обе цены из прайса; режим расчёта, процент и НДС задаются один раз в шапке заявки, а строка подтверждается одним кликом. Счёт №6824 в «МойСклад» сошёлся с предпросмотром до копейки. Распознавание файлов и изображений, нормализация оставшегося каталога остаётся следующей задачей. Excel-база: 96 462 материала и 117 433 ценовых предложения.

## Быстрый запуск

```powershell
Set-Location app
npm ci
npm run dev
```

Vite поднимает интерфейс на [http://127.0.0.1:5173](http://127.0.0.1:5173) и сам запускает локальный Python-сервис. Для демонстрационного режима без внешних API:

```powershell
$env:VITE_USE_MOCK = 'true'
npm run dev
```

## Что умеет

- **Каталог** — 90 тыс. материалов и 125 тыс. предложений поставщиков, фильтры по категории, поставщику, цене и весу, карточка материала с алиасами и объединением дублей.
- **Заявки** — три способа создать документ: распознать текст заявки клиента, собрать состав из каталога, ИИ-подбор по описанию.
- **Подбор** — до пяти вариантов на строку с классом «точное / возможное / аналог», выбор одним кликом; аналог требует отдельного подтверждения.
- **Позиции** — колонки «Себестоимость / Розница / Продажа»: цены подставляются из прайса, маржа считается на лету, подтверждение в один клик.
- **Расчёт в шапке заявки** — скидка или маржа и НДС задаются один раз; сервер пересчитывает цену к счёту по каждой строке, базовая розница не меняется.
- **Счета** — предпросмотр читает настройки заявки, отправка в «МойСклад», сверка до копейки, повтор отправки без дубля.
- **Реестр счетов** — фильтры по статусу, контрагенту, периоду и убыточности, шторка состава, переход к исходному документу.
- **Импорт и данные** — загрузка прайсов XLS/XLSX, журнал импорта, состояние SQLite и Parquet, системный журнал.

## Пример сценария

1. «Заявки» → «Новый документ» → «Распознать заявку»: вставить список материалов из письма.
2. Нажать «Запустить сопоставление ИИ»: товар, поставщик и обе цены подставятся из прайса; при неоднозначности раскрыть строку и выбрать вариант.
3. В шапке задать скидку или маржу и НДС; подтвердить строки — счётчик «Готово к счёту» покажет, что документ готов.
4. «Сформировать счёт» → проверить предпросмотр → создать документ в «МойСклад».
5. «Счета» → найти счёт по периоду, открыть состав или исходную заявку.

## Структура проекта

```text
app/                         React, TypeScript, Vite и оболочка Tauri
app/backend/                 FastAPI-сервис: заявки, счета, каталог, настройки
app/src/pages/               Экраны приложения
app/src/components/          Общие и предметные компоненты
app/src/lib/format.ts        Единое форматирование денег, дат и чисел
database/unified_catalog/    Каталог Parquet для desktop-ветки
input_doc/                   Исходные прайсы поставщиков
docs/                        Техническая документация
.ai-factory/plans/           Спецификации и планы работ
```
